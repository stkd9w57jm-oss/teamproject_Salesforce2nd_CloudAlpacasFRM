### 이루키 레코드가 자기모순 상태입니다

Fan Profile 상단 하이라이트에서 심사위원이 **가장 먼저 보는 4칸**:

| 항목 | 현재 값 |
|---|---|
| Favorite Player | 문태양 ✅ |
| **Fan Value Tier** | **(빈칸)** |
| **Engagement Level** | **(빈칸)** |
| **Current Segment** | **New Fan** |

그런데 바로 아래 Summary 탭의 같은 팬:

| 항목 | 값 |
|---|---|
| 경기 관람 횟수 | **3경기** |
| 티켓 구매 | 누적 3건 |
| 구장 굿즈 구매 | 1건 |
| 멤버십 | **Active** |
| LTV | **₩124,000** |
| **팬 건강도(참여도)** | **0** |

**멤버십까지 가입하고 3경기를 본 LTV 12만원 팬이 "New Fan"이고 "참여도 0"입니다.**
게다가 "세그먼트 기회" 화면은 같은 이루키를 **"멤버십 전환 완료 팬 · 성공 여정 완료"**의 대표 팬으로 소개합니다. 한 사람이 세 화면에서 세 가지로 나옵니다.

**왜 치명적인가**
1. 이 화면이 Scene 2·4·5·8 — **Core Scene 4개 중 3개**의 메인 화면입니다
2. Scene 4(Core ★)의 핵심이 *"실제로 경기장에 온 순간 Active Fan으로 자동 전환됩니다"*인데, **전환이 안 되어 있습니다.** 라이브로 보여줄 수가 없습니다
3. 심사 기준이 "페인포인트를 제대로 해결했는가"인데, Pain Point 3(세분화)의 증거 화면에서 주인공이 잘못 분류돼 있습니다

**원인 추정** — Segment 자동 전환 Flow가 이루키에게 실행되지 않았거나(과거 데이터로 적재되어 Record-Triggered Flow를 안 탐), `Engagement_Score__c` 공식이 TBD라 참여도가 0으로 굳어 있음(→ 1차 분석 §6에서 지적한 미확정 항목이 실제로 화면에 터진 것).

**조치** — 승우님과 오늘: ① 이루키 Segment를 Active Fan(또는 VIP 후보)으로 바로잡기 ② Fan Value Tier·Engagement Level 채우기 ③ 참여도 공식을 못 정하면 **게이지를 화면에서 빼기** (0으로 보이는 것보다 없는 게 낫습니다).

## 🔴 심각 — 김매니저의 업무 동선이 중간에 끊깁니다

"세그먼트 기회" 화면은 *"다음 행동을 결정하세요"*라고 안내합니다. 그런데:

| 버튼 | 실제 동작 |
|---|---|
| 대표 팬 검토 | ✅ Fan 360 요약이 우측에 뜸 |
| **대상 팬 보기** | ❌ **눌러도 아무 반응 없음** |
| 우측 Fan 360 패널 | ❌ 타임라인까지만. **조치로 넘어가는 버튼이 없음** |

조치 버튼(**"조치 완료 처리"**)은 존재합니다 — 다만 **Fan 레코드의 Recommended Actions 탭**에 따로 있습니다.
즉 기능은 다 만들어져 있는데 **두 화면이 서로 연결되어 있지 않습니다.**

지금 데모에서 김매니저는: 세그먼트 기회 화면 → 대표 팬 검토 → *(막다른 길)* → 수동으로 Fan List로 이동 → 이루키 검색 → Recommended Actions 탭 → 조치.

**조치** — 우측 Fan 360 패널 하단에 버튼 하나만 추가하면 됩니다. "조치 완료 처리"를 그대로 옮기거나, 최소한 "Fan 레코드 열기" 링크. **"대상 팬 보기"는 동작 안 하면 데모 전에 숨기세요** — 심사위원이 누릅니다.

이것만 되면 *"세그먼트 발견 → 대표 팬 확인 → 조치"*가 **한 화면에서 완결**되고, Pain Point 5의 "데이터는 많은데 Action이 없다"에 대한 답이 완성됩니다.
