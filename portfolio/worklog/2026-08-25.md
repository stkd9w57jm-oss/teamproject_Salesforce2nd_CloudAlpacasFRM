# 2026-08-25 — Partner Account Contacts 탭이 계속 안 보였던 이유

**한 줄 요약** · Partner Account 화면 Contacts 탭이 계속 빈 화면으로 뜨는 문제를 데이터 → FlexiPage 배선 → 렌더링 방식 순으로 가설을 좁혀가며 디버깅했고, 최종 원인은 Page Layout의 Related Lists 섹션이 통째로 비어 있었던 것이었다.

---

## 오늘의 목표

Partner 레코드타입 Account(Acme Partners, d'Alba, test 123 아론 등)에서 Contacts 탭을 열면 담당자가 하나도 안 보이는 문제 해결. 데이터는 정상적으로 존재하는 걸 미리 확인한 상태였다.

---

## 한 것

### 1. 데이터 연결 확인

Contact.AccountId, AccountContactRelation(IsDirect/IsActive)까지 SOQL로 직접 확인 → 전부 정상. Contact 레코드도, 관계도 문제없었다.

### 2. FlexiPage 탭 배선 확인·수정

`Account - Partner Account` Lightning Record Page의 메타데이터를 열람. "Contacts" 탭이 실제로 가리키는 facet에는 `relatedListApiName: "Users"`가 들어가 있었고, 진짜 Contacts 관련 리스트 컴포넌트는 엉뚱하게 "Partnership Activities" 탭 facet 안에 ActivityHistories와 함께 들어가 있었다. 배선을 바로잡아 Contacts 탭 ↔ Contacts 관련 리스트로 재연결했다. **그런데도 여전히 안 보임.**

### 3. Page Layout Related Lists 추가 (진짜 원인)

App Builder에서 컴포넌트를 열어보니 "This related list cannot be displayed because it is not in the current page layout." 경고가 떠 있었다. `Partner Account Layout`(Account 오브젝트 Partner 레코드타입에 할당된 classic Page Layout)의 Related Lists 섹션이 **완전히 비어 있었다.** Contacts, Opportunities, Cases, Activity History 전부 미등록 상태.

Setup → Object Manager → Account → Page Layouts → `Partner Account Layout`에서 Related Lists 팔레트로 Contacts / Opportunities / Cases / Activity History를 레이아웃에 드래그해서 추가 → Save로 해결.

---

## 막힌 것

> 이 섹션이 포트폴리오에서 제일 값어치 있다.

### "This related list cannot be displayed because it is not in the current page layout."

```
This related list cannot be displayed because it is not in the current page layout.
```

**원인** · Lightning Record Page(FlexiPage)의 "Related List - Single" 컴포넌트는 컴포넌트 자체 설정(어떤 관련 리스트를 가리키는지)만으로는 동작하지 않는다. 그 레코드타입에 할당된 classic Page Layout에도 같은 관련 리스트가 등록돼 있어야 화면에 렌더링된다. `Partner Account Layout`은 Phase 2(8/19) 때 새로 만들어졌는데, 이때 Related Lists 섹션을 채우는 걸 통째로 빠뜨린 상태였다.

**해결** · Page Layout 편집 화면 → Related Lists 팔레트에서 필요한 항목들을 레이아웃 본문에 드래그 → Save.

**배운 것** · 화면(FlexiPage)과 레이아웃(Page Layout)은 서로 다른 설정 레이어다. 화면 쪽 배선만 맞다고 관련 리스트가 뜨는 게 아니다. 새 Page Layout을 만들 때는 Related Lists 섹션을 반드시 채워야 하고, 관련 리스트가 안 보일 때는 컴포넌트 설정보다 **App Builder가 보여주는 경고 메시지를 먼저 확인**하는 게 훨씬 빠르다 — 오늘은 데이터 확인과 FlexiPage 배선 확인에 먼저 시간을 썼는데 실제 원인은 그 두 가지 모두와 무관한 Page Layout 쪽이었다.
